# チャットで操作できる機能一覧

すべての操作はチャット入力のみで行う。カレンダーはread-onlyの表示専用。

---

## イベント作成（ホスト）

| 入力例 | 処理 |
|---|---|
| 「来週の飲み会を作って」 | イベント名・日程候補の入力を促す |
| 「候補は月曜と水曜の夜」 | 候補日をカレンダーに追加 |
| 「締切は金曜日」 | 回答締切をセット |

作成完了後、イベントURLを発行する。

---

## 候補日の操作（ホスト）

| 入力例 | 処理 |
|---|---|
| 「火曜日も追加して」 | 候補日を追加 |
| 「月曜は削除して」 | 候補日を削除 |
| 「時間を19時に変えて」 | 直近の候補日の時間を変更 |

---

## 回答（参加者）

| 入力例 | 処理 |
|---|---|
| 「月曜は行けます」 | 該当日を○にセット |
| 「水曜は微妙です」 | 該当日を△にセット |
| 「金曜は無理です」 | 該当日を×にセット |
| 「名前は田中です」 | 回答者名をセット |

---

## 日時解析のルール（calc.mdより）

- `DURATION`（来週、明日など）→ 該当週の月曜、または翌日にセット
- `DATE`（○日、×曜）→ 現在より後で最初のその日付・曜日
- `TIME`（○時×分）→ 直近の対象日の時間を上書き
