# str_to_list.py

列挙された日時表現を含む日本語テキストを、日時単位のリストに分割するモジュール。

---

## 定数

```python
COORDINATING_TOKENS = {"と", "や", "とか", "・", "、", ","}
```

列挙の区切りとみなす表層形の集合。これらのトークンが分割候補になる。

```python
WEEKDAY_ABBR = {"月", "火", "水", "木", "金", "土", "日"}
```

ja_timex が単体では DATE として認識しない略称曜日の集合。`_normalize_weekday_abbr` での補完判定に使う。

---

## _find_timex_spans

```python
_find_timex_spans(text: str) -> list[tuple[int, int]]
```

`ja_timex` でテキスト中の時間表現を検出し、各 TIMEX3 スパンの `(start, end)` をリストで返す。

---

## _is_inside_any_span

```python
_is_inside_any_span(pos_start: int, pos_end: int, spans: list[tuple[int, int]]) -> bool
```

トークンの範囲 `[pos_start, pos_end)` がいずれかの TIMEX3 スパンの内部に完全に含まれるか判定する。

「14時と15時」の「と」のように、TIMEX の一部になっている区切り文字を誤って分割点にしないために使う。

---

## _find_split_positions

```python
_find_split_positions(text: str, spans: list[tuple[int, int]]) -> list[tuple[int, int]]
```

MeCab で形態素解析し、`COORDINATING_TOKENS` に属するトークンのうち TIMEX3 スパンの**外側**にあるものの位置 `(start, end)` を返す。

### 動作

1. MeCab でノードを順に走査しながら文字位置 `pos` を追跡する
2. トークンが `COORDINATING_TOKENS` に含まれる場合、`_is_inside_any_span` でチェック
3. スパン外であれば `(token_start, token_end)` を `split_positions` に追加する

---

## _normalize_weekday_abbr

```python
_normalize_weekday_abbr(chunks: list[str]) -> list[str]
```

略称曜日（月/火/水/木/金/土/日）に「曜」を補い、ja_timex が認識できる正式形に正規化する。

### 背景

ja_timex は「月曜」「水曜」は `DATE` として認識するが、「月」「水」など1文字の略称は認識しない。そのまま `resolve_datetime` に渡すと曜日情報が消えてサイレントに誤った結果を返すため、propagate の前に正規化する。

### 動作

チャンク内の全文字を走査し、以下の3条件を**すべて**満たす位置に「曜」を挿入する。

1. `WEEKDAY_ABBR` に含まれる文字である
2. ja_timex のスパンに覆われていない（「今日」の「日」・「1月」の「月」などは除外）
3. 直後がすでに「曜」でない

末尾のみを見る実装だと「水の15時」のようにチャンク途中の略称が取りこぼされるため、全文字走査にしている。

### 例

| 入力 | 出力 |
|------|------|
| `["来週の月", "水", "金曜の15時"]` | `["来週の月曜", "水曜", "金曜の15時"]` |
| `["水の15時"]` | `["水曜の15時"]`（チャンク途中の略称も補完） |
| `["今日", "明日の15時"]` | `["今日", "明日の15時"]`（ja_timex が認識済みなので変化なし） |
| `["月曜の10時", "水曜の15時"]` | `["月曜の10時", "水曜の15時"]`（直後が「曜」なので変化なし） |

## _propagate_prefix

```python
_propagate_prefix(chunks: list[str]) -> list[str]
```

先頭チャンクに週修飾子（来週・先週など）がある場合、その修飾子を後続の曜日チャンクへ補完する。`_normalize_weekday_abbr` の後に実行するため、略称曜日はすでに正式形になっている前提。

### 動作

1. 先頭チャンクを TimexParser でパースし、`DURATION` かつ value に `"W"` を含む timex（週修飾子）があるか確認する
2. 週修飾子がなければそのまま返す
3. プレフィックス境界を決定する
   - 先頭チャンクに DATE timex がある場合（正規化後は常にこちら）: 最初の DATE timex の開始位置
   - DATE timex がない場合（フォールバック）: DURATION timex の終端 + `"の"`
4. 後続チャンクを順に確認し、`XXXX-WXX-N` 形式の DATE timex を持つチャンク（週コンテキストなしの曜日）にプレフィックスを付与する

### 例

| 入力 | 出力 |
|------|------|
| `["来週の月曜", "水曜", "金曜の15時から17時"]` | `["来週の月曜", "来週の水曜", "来週の金曜の15時から17時"]` |
| `["来週の水曜", "木曜"]` | `["来週の水曜", "来週の木曜"]` |
| `["月曜の10時", "水曜の15時"]` | `["月曜の10時", "水曜の15時"]`（週修飾子なし） |

---

## _propagate_suffix

```python
_propagate_suffix(chunks: list[str]) -> list[str]
```

最後のチャンクが「DATE + 時刻などのサフィックス」という構造を持つ場合に、サフィックスを TIME timex を持たない先行チャンクへ補完する。

### 動作

1. 最後のチャンクを TimexParser でパースする
2. `TIME` 以外の最後の TIMEX の終端位置以降の文字列をサフィックスとして抽出する
   - ※ 先頭 TIMEX を境界にすると `"来週の木曜"` の `"の木曜"` が誤って伝播するため、TIME 以外の**最後の** TIMEX を使う
3. 先行チャンクを順に確認し、TIME timex を持たないチャンクにサフィックスを付与する

### 例

| 入力 | 出力 |
|------|------|
| `["来週の月曜", "来週の水曜", "来週の金曜の15時から17時"]` | `["来週の月曜の15時から17時", "来週の水曜の15時から17時", "来週の金曜の15時から17時"]` |
| `["月曜の10時", "水曜の15時"]` | `["月曜の10時", "水曜の15時"]`（先行チャンクに TIME があるので変化なし） |
| `["来週の水曜", "来週の木曜"]` | `["来週の水曜", "来週の木曜"]`（サフィックスなし） |

---

## str_to_list

```python
str_to_list(text: str) -> list[str]
```

入力テキストを、列挙されている日時表現の単位で複数の文字列に分割して返す。

### 動作フロー

1. `_find_timex_spans` で TIMEX3 スパンを取得する
2. `_find_split_positions` で区切りトークンの位置を取得する
3. `split_positions` を start 順にソートし、区切りトークンを除外しながらテキストをスライスして `result` を構築する
4. `_normalize_weekday_abbr` で略称曜日（「月」「水」など）を正式形（「月曜」「水曜」）に正規化する
5. `_propagate_prefix` で先頭チャンクの週修飾子を後続チャンクへ補完する
6. `_propagate_suffix` で最後のチャンクの時刻サフィックスを先行チャンクへ補完する
7. リストを返す

### 使用例

```python
str_to_list("来週の月、水・金曜の15時から17時")
# -> ["来週の月曜の15時から17時", "来週の水曜の15時から17時", "来週の金曜の15時から17時"]

str_to_list("来週の水曜と木曜")
# -> ["来週の水曜", "来週の木曜"]

str_to_list("月曜・水曜・金曜の15時")
# -> ["月曜の15時", "水曜の15時", "金曜の15時"]

str_to_list("月曜の10時と水曜の15時")
# -> ["月曜の10時", "水曜の15時"]

str_to_list("来週の水曜日と木曜日")
# -> ["来週の水曜日", "来週の木曜日"]
```
